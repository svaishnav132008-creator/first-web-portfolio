# First Web Portfolio

A responsive creative portfolio built with HTML, CSS, vanilla JavaScript, Vite, GSAP, ScrollTrigger, and Lenis.

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

## Build

```powershell
npm.cmd run build
```

Vite writes the production site to `dist/`. Fonts, animation libraries, smooth scrolling, and portfolio photography load from external services.

## GitHub Pages

The GitHub Actions workflow builds and deploys the site to GitHub Pages when changes are pushed to `main`.
